# Agenda

**Agenda** é um aplicativo de gestão de aluguéis de roupas desenvolvido com Kivy e Python. Ele permite gerenciar aluguéis, visualizar calendários e manter registros usando um banco de dados integrado.

## **Descrição do Projeto**
Este projeto oferece uma interface gráfica para uma loja de roupas de aluguel. Ele permite registrar clientes, roupas disponíveis e aluguéis, exibindo informações organizadas em um calendário interativo.

### **Funcionalidades Implementadas**
- Exibição de calendário interativo.
- Registro de aluguéis e clientes.
- Visualização de aluguéis por data.
- Interface de fácil navegação e interação.

## **Tecnologias Utilizadas**
- **Python:** Linguagem principal para desenvolvimento.
- **Kivy:** Framework para criação de aplicativos GUI.
- **SQLite:** Gerenciamento de banco de dados local.

## **Como Executar**
1. Clone o repositório:
   ```bash
   git clone https://github.com/usuario/loja-roupas-aluguel.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd loja-roupas-aluguel
   ```
3. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
4. Execute o aplicativo:
   ```bash
   python main.py
   ```
